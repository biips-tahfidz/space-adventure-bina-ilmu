🗄️ Sinkronisasi & Pengamanan Data ke Database Supabase

Memeriksa koneksi Supabase...

Catatan Teknis Database: Aplikasi ini otomatis menyimpan seluruh data (Profil Sekolah, Guru, Siswa, Mapel, Bank Soal, dan Nilai) ke tabel school_kv_store, soal, dan hasil_ujian di Supabase Anda. Jika tabel school_kv_store belum dibuat di SQL Editor Supabase, jalankan perintah SQL berikut sekali saja: 

CREATE TABLE IF NOT EXISTS public.school_kv_store (
  key TEXT PRIMARY KEY,
  data JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE public.school_kv_store ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Akses publik school_kv_store" ON public.school_kv_store FOR ALL USING (true) WITH CHECK (true);
